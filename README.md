# homebrew-fukujin

Homebrew tap for [FukuJin](https://github.com/s-age/FukuJin) — a macOS menu bar
app that pins other apps' windows as live floating overlays.

## Install

```bash
brew tap s-age/fukujin
brew install --cask fukujin
```

Requires macOS 15 (Sequoia) or later. The app is signed with a Developer ID
certificate and notarized by Apple.
